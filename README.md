# Faisal Talukdar — Personal Brand / Performance Marketing Website

Static HTML/CSS/JS package for GitHub Pages.

## Included
- Premium warm visual system
- Responsive mobile/desktop navigation
- Meta Ads, Google Ads, Market Research, Lead Generation, Business Growth and AI-assisted marketing services
- Platform + AI tool marquee
- Selected work / case-study structure
- Blog / insights section
- Contact form with the preserved Formspree endpoint
- YouTube, LinkedIn, Facebook, Email and WhatsApp destinations
- SEO metadata, canonical URLs, sitemap, robots.txt, Person and BlogPosting schema
- 404 and privacy starter page
- Local image assets and social-share artwork

## Deploy
Upload the contents of this folder to the GitHub Pages repository root. The package is already configured for the current GitHub Pages URL used in the project.

Future case-study and proof slots are intentionally structured without invented performance numbers. Add verified metrics, screenshots, client context and testimonials as they become available.
